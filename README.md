# SmartLedger 智能记账

一款 Android 智能记账应用，支持自动识别微信、支付宝、云闪付、银行卡的支付通知并自动记账。

## ✨ 功能特点

### 🤖 自动记账
- **多渠道监听**：自动识别微信、支付宝、云闪付支付通知
- **银行支持**：工商银行、邮政储蓄、建设银行、中国银行、农业银行、招商银行、平安银行等 10+ 家银行
- **双向识别**：同时支持支出（消费）和收入（退款、转账、红包）
- **智能去重**：同一笔交易不会重复录入（跨渠道通知自动合并）
- **智能分类**：根据商户名自动匹配分类（餐饮/交通/购物/娱乐等）
- **权限检测**：重新安装后自动检测并提醒开启通知监听权限

### 📊 数据统计
- 日/周/月/年多维度统计
- 环形图展示分类占比
- 分类排行榜
- 收支趋势分析

### 💰 预算管理
- 月度预算设置
- 分类预算
- 预算使用进度提醒

### 📱 其他功能
- 手动记账
- 数据导出（CSV）
- 数据备份/恢复
- 分类管理（添加/编辑/删除）
- 设置页面

## 🚀 安装方式

### 方式一：下载 APK（推荐）

1. 前往 [Releases](https://github.com/huanghhcri/SmartLedger/releases) 页面
2. 下载最新版本的 `app-release.apk`
3. 在手机上安装（需要开启"允许安装未知来源应用"）

### 方式二：自行编译

```bash

git clone https://github.com/huanghhcri/SmartLedger.git
cd SmartLedger

# 2. 用 Android Studio 打开项目

# 3. 连接手机或启动模拟器

# 4. 点击 Run 运行
```

## ⚠️ 已知问题与限制

### 1. 通知监听不稳定
- **问题**：部分手机（尤其是小米/华为/OPPO/vivo）可能会在后台杀掉通知监听服务
- **解决**：
  - 开启自启动权限
  - 关闭电池优化
  - 锁定 App 在后台（最近任务中下拉锁定）

### 2. 重新安装后权限丢失
- **问题**：重新编译安装后，通知监听权限会自动撤销
- **解决**：App 会自动检测并弹窗提醒，点击「去开启」即可

### 3. 部分通知格式不支持
- **问题**：某些银行 App 的通知格式可能无法识别
- **解决**：手动记账，或联系我们添加新的解析规则

### 4. 智能分类不够精准
- **问题**：部分商户名可能无法正确匹配分类
- **解决**：在交易详情中手动修改分类

### 5. 暂不支持深色模式
- **问题**：当前只有浅色主题
- **计划**：后续版本会添加深色模式支持

### 6. 暂无云端同步
- **问题**：数据只保存在本地，换手机会丢失
- **解决**：使用「数据备份」功能导出，再在新手机「恢复」
